## Proyecto 🔥

Esta carpeta contiene el código fuente, los rescursos y la documentación utilizada para el desarrollo de este proyecto.

### Estructura de la Carpeta 📚

```text
    Proyecto/
        |__bin/
        |__data/
        |__include/
        |__src/

```

### **1. bin/** ⚙️

Aquí se guardarán los archivos ejecutables generados después de compilar el código fuente.

### **2. data/** 📊

Carpeta destinada a almacenar archivos externos que el programa necesite leer o escribir, como archivos de texto (.txt), imagenes, bases de datos o configuraciones de entrada

### **3. include/** 🔗

Espacio reservado para los archivos de cabecera (headers) con extensión .h o .hpp. Aquí se definen las clases y funciones que luego se usan en el código principal.

### **4. src/** 🛠️

Aquí se almacenan todos los archivos de código fuente (.cpp) donde se programa la lógica funcional de cada clase (o funciones) y el archivo principal (main.cpp).
